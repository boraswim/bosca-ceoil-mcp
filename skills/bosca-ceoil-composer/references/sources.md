# Reference sources

Use reference material to learn techniques, like tempo, form, density and how a sound changes over time. Don't copy melodies or audio into a song or into this skill.

Before downloading anything to study:

1. Read the licence on that specific item. A site's general licence doesn't always cover every upload.
2. Check whether its terms limit use for AI, and check `robots.txt` before scripting downloads. Follow any crawl delay.
3. Keep a small labelled sample in a temporary folder, record each item's source and licence, and delete the files when finished.

## Good to study

| Source | Licence | Best for |
|---|---|---|
| [jsfxr](https://github.com/chr15m/jsfxr) | Unlicense | How retro SFX are built: its presets cover coin, laser, explosion, power-up, hit, jump and blip |
| [Kenney](https://kenney.nl/assets/category:Audio) | CC0 | Game-ready UI and impact sounds to measure |
| [OpenGameArt](https://opengameart.org/) | Varies by upload, and many are CC0 | Game music as MIDI, and SFX packs. Check each upload's licence |
| [Mutopia Project](https://www.mutopiaproject.org/legal.html) | Public domain or CC, varying by piece | Harmony and form in classical pieces. CC BY-SA pieces carry share-alike terms |
| [Incompetech](https://incompetech.com/music/royalty-free/music.html) | CC BY 4.0, with credit required | Tempo, feel and instrumentation data across a large catalogue. Credit Kevin MacLeod |

## Check before using

| Source | Why |
|---|---|
| [Sonniss GameAudioGDC](https://sonniss.com/gameaudiogdc/) | Its [licence](https://sonniss.com/gdc-bundle-license/) bars using the sounds to develop, train or enhance AI without written permission from Sonniss, so don't study these sounds for this skill or for AI output without that permission. A game developer can still use them directly in a finished game under that licence. |
| [BitMidi](https://bitmidi.com/) | It states no licence for its files, and many are commercial songs. Its `robots.txt` disallows automated access to `/uploads/`, so don't script downloads. Only study files the user has downloaded themselves and accepted the risk for, and only extract general statistics. |
